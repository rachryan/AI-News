# Security Policy

TechTidy is a small, independently maintained static website and learning project. Responsible reports that help protect visitors and the integrity of the site are appreciated.

## Supported Versions

TechTidy does not publish numbered software versions.

| Component | Supported |
| --- | --- |
| Live website at [techtidy.ca](https://techtidy.ca) | Yes |
| Latest code on the `main` branch | Yes |
| Older commits, forks or downloaded copies | No |

## Reporting a Vulnerability

Please do not report suspected security vulnerabilities through a public GitHub issue, discussion or website form.

Use GitHub’s private vulnerability reporting:

[Report a security vulnerability privately](https://github.com/rachryan/AI-News/security/advisories/new)

Please include, where possible:

- The affected page, file or URL
- A clear description of the issue
- Steps needed to reproduce it
- The potential impact
- Screenshots or a minimal proof of concept
- Suggestions for resolving the issue

Do not include passwords, access tokens, personal information or data belonging to another person.

## Response

TechTidy will aim to:

- Acknowledge a report within five business days
- Review the issue and ask for additional information if needed
- Prioritize fixes according to likely impact and risk
- Keep the reporter reasonably informed while the issue is assessed

These are reasonable targets for a small independently maintained project, not guaranteed service levels.

## Responsible Testing

Good-faith security research is welcome when it is limited to what is necessary to demonstrate an issue.

Please do not:

- Access, change, retain or disclose another person’s information
- Attempt to obtain passwords, authentication tokens or private credentials
- Submit spam or large numbers of form requests
- Perform denial-of-service or other availability testing
- Use social engineering, phishing or physical attacks
- Install malware or create persistent access
- Publicly disclose an unresolved vulnerability before TechTidy has had a reasonable opportunity to respond

If testing exposes personal information or credentials, stop immediately and report the issue privately.

## Scope

The following are in scope:

- `https://techtidy.ca`
- Code maintained in this repository
- Security problems caused by TechTidy’s configuration or integration choices

The following third-party services are outside TechTidy’s direct control:

- GitHub and GitHub Pages
- Formspree
- Google Analytics and Google Fonts
- External websites linked from TechTidy

Vulnerabilities in those services should be reported directly to the relevant provider. Problems caused by how TechTidy uses a third-party service may still be reported here.

## Disclosure and Recognition

Please allow a reasonable period for investigation and remediation before publishing details.

TechTidy does not currently operate a paid bug-bounty program. Reports may be acknowledged publicly with the reporter’s permission.
