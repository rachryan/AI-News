LEARNING PATH

Technology Fundamentals

Start with the parts of a device you can touch, then build toward the software, internet services, and data systems working behind everyday technology. No technical background is assumed.

What You'll Learn

  • The difference between hardware, software, and data
  • When a file or database is the better way to organize information
  • How records, fields and searches make databases useful
  • What cloud services are and how your device reaches them
  • How APIs let digital services exchange selected information

How to Use This Path

Start with Lesson 1 if the terms feel new. Each lesson takes about 12–14 minutes and includes a short activity and knowledge check. You can also open the lesson that answers your immediate question.

No account or special software needed

Every activity can be completed remotely using the page itself, a keyboard, a screen reader, or a piece of paper. Practice examples use fictional or non-sensitive information.
