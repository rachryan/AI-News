Hardware vs. Software

Every digital device depends on two things working together: physical parts you can touch and instructions that tell those parts what to do.

Beginner · About 12 minutes · Includes an activity and knowledge check

What You’ll Learn

  • What hardware and software mean in everyday language
  • How they depend on each other
  • How to sort familiar technology into useful categories
  • How the difference can help when something goes wrong

Two Parts of One Working System

Hardware is the physical equipment. If you can touch it, plug it in, carry it, or replace it, it is probably hardware.

Software is the set of instructions that runs on the equipment. It tells the hardware how to perform a task.

Think of a music player

The phone and its speaker are hardware. The music app is software. The song file is information the software reads. You need all three, but they are not the same thing.

What Counts as Hardware?

Hardware includes the parts you see and the components hidden inside a device.

INPUTKeyboard, mouse, touchscreen, microphone and camera—parts used to give information to a device.
OUTPUTScreen, speakers and printer—parts that present information back to you.
STORAGEInternal drive, USB drive and memory card—parts that keep files and information.
PROCESSINGThe processor and working memory inside the device—parts that carry out instructions while you work.
CONNECTIONRouter, network port and wireless components—parts that help devices communicate.

A laptop, phone, tablet, smart television and printer are all hardware. Each is a physical device that contains other hardware components.

What Counts as Software?

Software cannot do anything by itself. It must run on hardware, but it determines what that hardware can help you accomplish.

OPERATING SYSTEMWindows, macOS, Android, ChromeOS and iOS manage the device and allow other software to run.
APPLICATIONMicrosoft Word, Zoom, a calculator or a photo editor helps you complete a particular task.
BROWSERChrome, Safari, Edge and Firefox are applications used to open websites and web-based services.
BUILT-IN SOFTWAREPrinters, routers and other equipment contain software that controls their basic functions.

A useful shortcut

Hardware is the equipment. Software is the instructions. A file—such as a photograph or document—is information that software can open, change and save.

How They Work Together

Imagine typing a sentence into a document:

  1. You press a physical key on the keyboard.
  2. The operating system recognizes the key.
  3. The word-processing application places the letter in your document.
  4. The physical screen displays it.
  5. When you save, the file is written to physical storage in your device or to hardware in a remote data centre.

This happens quickly, so it feels like one action. In reality, several pieces of hardware and software cooperate every time you press a key.

Common Points of Confusion

Is “the cloud” hardware or software?

A cloud service feels like software because you use an app or website. Behind it are physical servers, storage devices and networking equipment in data centres. Cloud services depend on both.

Is a website software?

A website is digital content delivered through software. Your browser interprets its code and displays it using your device’s hardware.

Is a file software?

Usually, no. A photograph, document or video is data. Software is what lets you create, open or change that data.

What about something with software built inside it?

Many physical products contain built-in software. A smart television is hardware, for example, while its menus and streaming applications are software.

Why the Difference Helps With Troubleshooting

You do not need to diagnose every problem yourself. Knowing which area is affected simply helps you describe the problem and choose a sensible first step.

LIKELY HARDWAREThe device is physically damaged, will not power on, makes an unusual sound, or a cable or button is broken.
LIKELY SOFTWAREOne application freezes, a menu disappears, an update changes behaviour, or an error appears while the device still works.
COULD BE EITHERA camera, printer or speaker stops working. The equipment may be disconnected, or the software may not have permission to use it.

Change one thing at a time

Check the connection, note any visible error, restart the affected application, and then restart the device if appropriate. Avoid changing several settings at once because that makes the cause harder to identify.

Quick Knowledge Check

1. Which example is software?

A printer, a web browser, or a USB drive?

Answer

A web browser. It is an application that runs on hardware.

2. Can hardware be useful without software?

Answer

Usually not. Software provides the instructions that make most digital hardware useful.

3. Your video-call application opens, but it cannot use the camera. Is the camera definitely broken?

Answer

No. The hardware may be working, while the application lacks permission or has the wrong software setting.

What to Remember

  • Hardware is the physical equipment.
  • Software is the instructions that run on the equipment.
  • Data is the information that software creates, opens or changes.
  • Most technology experiences depend on hardware and software working together.
  • Understanding the difference helps you explain problems more clearly.
